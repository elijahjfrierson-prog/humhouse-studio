# HumHouse Studio keyboard shortcuts

Mapped from Image-Line's published FL Studio shortcut list
(fl-studio-online-manual/html/basics_shortcuts.htm and the piano roll tool pages).
Ctrl = Cmd on macOS, Alt = Option.

## Global / transport
| Keys | Action |
|---|---|
| Space | Play / stop |
| Ctrl+Space | Play / pause |
| L | Switch Pattern / Song mode |
| R | Record on/off |
| Ctrl+M | Metronome |
| Ctrl+P | Recording count-in (precount) |
| Ctrl+H | Panic (stop all sound) |
| Ctrl+T | Typing keyboard to piano |
| Ctrl+Z / Ctrl+Alt+Z | Undo / undo step-by-step |
| Ctrl+Y / Ctrl+Shift+Z | Redo |
| Ctrl+S / Ctrl+Shift+S / Ctrl+O / Ctrl+N | Save / Save as / Open / New |
| Ctrl+R | Export WAV |
| Ctrl+Shift+M | Export MIDI (pattern) |
| F5 / F6 / F7 / F9 | Playlist / Channel Rack / Piano Roll / Mixer |
| F8 | Plugin picker (built-ins + scanned VST3/AU) |
| Alt+F8 | Browser (samples, kits) |
| F12 | Close tool windows |
| Esc | Close dialog / tool |
| Numpad + / - , 1-9 | Next / previous / select pattern |
| F4 / Ctrl+F4 | New (next empty) pattern |
| F2 | Rename pattern |

## Channel Rack
| Keys | Action |
|---|---|
| 1..9, 0 | Mute first 10 channels |
| Ctrl+1..9, 0 | Solo first 10 channels |
| Up / Down | Select channel |
| Alt+Up / Alt+Down | Move channel |
| Alt+C | Clone channel |
| Alt+Del | Delete channel |
| Ctrl+L | Route channel to a free mixer track |
| Ctrl+C / Ctrl+V / Ctrl+X | Copy / paste / cut steps |
| Ctrl+Shift+Left/Right | Shift steps left/right |
| Right-click step | Roll the step (1/2, 1/3, 1/4, 1/6, 1/8) |

## Piano Roll
| Keys | Action |
|---|---|
| P / B / D / E / C / T / Z | Draw / Paint / Delete / Select / Slice / Mute / Zoom tool |
| Alt (hold) | Bypass snap |
| Backspace | Toggle snap |
| Del | Delete selected |
| Ctrl+A / Ctrl+D / Shift+I | Select all / deselect / invert selection |
| Ctrl+C / Ctrl+X / Ctrl+V | Copy / cut / paste |
| Ctrl+B | Duplicate selection to the right |
| Shift+Up / Shift+Down | Transpose a semitone |
| Ctrl+Up / Ctrl+Down | Transpose an octave |
| Shift+Left / Shift+Right | Move selection one snap |
| Ctrl+Shift+Left/Right | Rotate (wrap) one snap |
| Alt+Arrows | Nudge |
| Shift+D | Discard lengths |
| Ctrl+G | Glue notes |
| Ctrl+L | Quick legato |
| Ctrl+Alt+Q | Quick quantize |
| Shift+Q | Quick quantize start times |
| Ctrl+U | Quick chop (to snap) |
| Alt+M / Alt+Shift+M | Mute / unmute selection |
| Shift+R | Select at random |
| **Alt+A** | **Arpeggiator / roll tool** - chord or single note repeated at a rate (1/8..1/64, triplets), range, up/down/alternate, gate, velocity ramp. Single note = snare/hat roll. |
| **Alt+S** | **Strum tool** - offsets chord-note start times (+ low->high, - high->low), tension (accelerate), velocity change per note, preserve end, alternate direction. |
| Alt+U | Chop tool - slice notes into a rate, with gate |
| Alt+F | Flam tool - grace hit before each note (time, velocity) |
| Alt+Q | Quantize tool - strength, start/length |
| Alt+R | Randomize tool - random notes in key/scale, population, velocity |
| Alt+K | Limit tool - fold notes into the project key/scale and a key range |
| Alt+L | Articulate tool - legato / staccato length scaling |
| Alt+X | Scale levels - velocity multiply / offset |
| Alt+Y | Flip tool - flip in time and/or pitch |
| Alt+W | Claw machine - remove every Nth slice, time distortion (rush/bounce) |
| Alt+O | LFO tool - sweep velocity with a sine/tri/square |

## Playlist
| Keys | Action |
|---|---|
| P / B / D / E / C / T | Draw / Paint / Delete / Select / Slice / Mute tool |
| Ctrl+B | Duplicate selection to the right |
| Del | Delete selected clips |
| Home | Playhead to start |
| PgUp / PgDown | Zoom in / out |
| 9 | Reverse audio clip |
| 7 / 8 | Transpose clip down / up |
| Alt+M / Alt+Shift+M | Mute / unmute clips |

## Mixer
| Keys | Action |
|---|---|
| S | Solo current track |
| Alt+Left / Alt+Right | Select track left / right |
| F2 | Rename track |
| Click the arrow under a strip | Route the selected track to it (click again to unroute) |
